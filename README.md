## Lesson 3 - simple input & output ( printf, scanf, placeholder )

- Print a number

We use `%d` as a placeholder for the integer
We use `%f` as a placeholder for a decimal number (float)

```C
#include <stdio.h>
#include <stdlib.h>

int main()
{
    printf("%d", 32);
    printf("%f", 45.6);
    return 0;
}

```
```C
#include <stdio.h>
#include <stdlib.h>

int main()
{
    printf("Hello world!\n");
    printf("Hello world!\n");
    printf("The number is = %d", 32);
    return 0;
}
```

- To print spaced many numbers

```C
#include <stdio.h>
#include <stdlib.h>

int main()
{
    printf("%d %d %d", 32, 56, 90);
    return 0;
}

```
